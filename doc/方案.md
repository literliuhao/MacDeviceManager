iPad Pro 无线自动充电完整方案（pymobiledevice3 WiFi）
整体拓扑（无任何数据线常驻）
plaintext
iPad Pro (USB-C口只接充电器)
    │
    └── 充电器 ──→ 小米智能插座3 (WiFi, 局域网可控)
                        │
MacBook Air M4 ──WiFi──┘
    │
    ├── pymobiledevice3 ←──WiFi/Bonjour──→ iPad (读取电量)
    ├── python-miio    ──WiFi局域网──→ 小米插座 (开关控制)
    └── sleepwatcher / launchd (守护进程 + 休眠钩子)
iPad 的 USB-C 口完全留给充电器，Mac 和 iPad 之间全程走 Wi-Fi 通信，零物理连线。

> 注：本方案命令已根据 **pymobiledevice3 v10.7+** 新版 CLI 更新；如果跑在 v2/v3 老版本，部分命令（list-devices / diagnostics battery / wifi-connections）形态略有差异，代码已自动兼容。

第一步：环境安装（Mac 端）
bash
# 1. 安装 pymobiledevice3（iOS 设备无线通信）
pip3 install -U pymobiledevice3

# 2. 安装 python-miio（小米插座局域网控制）
pip3 install python-miio

# 3. 验证安装
python3 -m pymobiledevice3 version
python3 -m miiocli --help

第二步：一次性无线配对
> 【WiFi-only 用户提示】如果你**之前已经在这台 Mac 上**用 USB 插过 iPad、并在 iPad 上点过「信任此电脑」，则可以跳过下面 2.2 的 USB 环节，直接从 2.3B「纯无线二次验证」开始。
> 如果是**新设备 / 从未在这台 Mac 上信任过**，必须先走 2.1 + 2.2 的 USB 信任流程一次，之后才能完全无线。

iPad 连接 Wi-Fi（和 Mac 同一个局域网，必须 2.4G/5G 同网段）
设置 → 隐私与安全性 → 开发者模式 → 开启开发者模式（需要重启 iPad）
重启后再次进入，确认开发者模式已启用

2.2 USB 配对 + 开启 Wi-Fi 调试（仅首次/未信任过需要）

# 若多台：python3 -m pymobiledevice3 lockdown wifi-connections --state on --udid 你的UDID

2.3A 刚走完 USB 配对的用户

python3 -m pymobiledevice3 usbmux list
# 如果列表中仍出现 iPad，说明无线配对已启用

2.3B WiFi-only / 之前已配对过的用户（跳过 USB，直接验证）
bash
# 方式 A：usbmuxd 枚举（USB + WiFi）
python3 -m pymobiledevice3 usbmux list
# 方式 B：Bonjour 纯局域网发现（无线设备）
python3 -m pymobiledevice3 bonjour mobdev2

# 先记 UDID，填到 config/plug_config.yaml → ipad_charger.udid

# 读取电量（v10 新命令：diagnostics battery single；WiFi 推荐 --tunnel，见 2.4 tunneld 启动后）
python3 -m pymobiledevice3 diagnostics battery single

如果 battery single 报 "No device" 或连接错误，说明需要先建 tunneld 隧道（尤其 iPadOS 17+），见 2.4。

2.4 iPadOS 17+：启动无线隧道（tunneld 后台服务）
iOS 17 及以上，部分服务需要通过 CoreDevice tunnel 访问。用 tunneld 做自动隧道管理，最省心：
bash
# 启动 tunneld 后台服务（需要 sudo，会自动发现局域网设备并建立隧道）
sudo python3 -m pymobiledevice3 remote tunneld &

# 验证隧道状态
python3 -m pymobiledevice3 remote rsd-info

# tunneld 起来后，读电量推荐用 --tunnel（无线隧道，最稳定）
python3 -m pymobiledevice3 diagnostics battery single --tunnel 你的UDID

tunneld 会常驻后台，自动维护 iPad 的无线隧道。建议做成 launchd 开机自启（ipad/com.hermes.pymobiledevice3-tunneld.plist 已准备好）。

第四步：完整监控脚本
把下面脚本保存为 ~/ipad_autocharge/ipad_charge.py：
python
运行
#!/usr/bin/env python3
"""
iPad Pro 无线自动充电监控脚本
- 通过 pymobiledevice3 WiFi 读取 iPad 电量
- 通过 python-miio 控制小米智能插座
- 阈值：≤25% 开充，≥80% 停充
- 连续读取失败 → 强制关闭插座（安全保护）
"""

import subprocess
import json
import time
import sys
import logging
from datetime import datetime

# ============ 配置区 ============
IPAD_UDID = "你的iPad_UDID"           # 从 python3 -m pymobiledevice3 usbmux list 获取
PLUG_IP = "192.168.x.x"                # 小米插座局域网IP
PLUG_TOKEN = "你的插座token"           # 小米插座token
LOW_THRESHOLD = 25                     # 低于此电量开始充电
HIGH_THRESHOLD = 80                    # 高于此电量停止充电
CHECK_INTERVAL = 30                    # 轮询间隔（秒）
MAX_FAIL_COUNT = 3                     # 连续读取失败次数上限，超限强制关插座
LOG_FILE = "/Users/你的用户名/ipad_autocharge/charge.log"
PY = "/usr/bin/env python3"            # 建议用与 pip 同环境的 python3
# ================================

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
    handlers=[
        logging.FileHandler(LOG_FILE),
        logging.StreamHandler()
    ]
)
log = logging.getLogger(__name__)

fail_count = 0
current_plug_state = None  # None=未知, True=开, False=关


def get_ipad_battery():
    """通过 pymobiledevice3 无线读取 iPad 电量，返回 (电量百分比, 是否充电中)
    pymobiledevice3 v10+ 起命令必须是 diagnostics battery single；
    WiFi 模式优先 --tunnel UDID（tunneld 隧道），老版本自动 fallback。"""
    try:
        # 候选命令：按优先级依次尝试
        candidates = []
        if IPAD_UDID:
            candidates.append([PY, "-m", "pymobiledevice3", "diagnostics", "battery", "single",
                               "--tunnel", IPAD_UDID])
            candidates.append([PY, "-m", "pymobiledevice3", "diagnostics", "battery", "single",
                               "--udid", IPAD_UDID])
            candidates.append([PY, "-m", "pymobiledevice3", "diagnostics", "battery",
                               "--udid", IPAD_UDID])  # 老版本兼容
        candidates.append([PY, "-m", "pymobiledevice3", "diagnostics", "battery", "single"])
        candidates.append([PY, "-m", "pymobiledevice3", "diagnostics", "battery"])  # 老版本

        result = None
        for cmd in candidates:
            result = subprocess.run(cmd, capture_output=True, text=True, timeout=15)
            out = (result.stdout or "").strip()
            err = (result.stderr or "").strip()
            if out and "No such command" not in err and result.returncode == 0:
                break
            if out and ("BatteryPercent" in out or "CurrentCapacity" in out):
                break
        if result is None or result.returncode != 0:
            log.error(f"读取电量失败: {(result.stderr if result else '').strip()}")
            return None, None

        # 解析输出（pymobiledevice3 输出为 JSON 或 key: value 格式）
        output = result.stdout.strip()
        try:
            data = json.loads(output)
            battery = data.get("BatteryPercent", data.get("CurrentCapacity"))
            charging = data.get("IsCharging", data.get("Charging"))
        except json.JSONDecodeError:
            # 纯文本输出，逐行解析
            battery = None
            charging = None
            for line in output.split("\n"):
                line = line.strip()
                if "BatteryPercent" in line or "CurrentCapacity" in line:
                    battery = int(line.split(":")[-1].strip())
                if "IsCharging" in line or "Charging" in line:
                    charging = "true" in line.lower() or "yes" in line.lower()
        return battery, charging
    except subprocess.TimeoutExpired:
        log.error("读取电量超时（15s）")
        return None, None
    except Exception as e:
        log.error(f"读取电量异常: {e}")
        return None, None


def set_plug(on: bool):
    """开关小米插座"""
    global current_plug_state
    action = "开启" if on else "关闭"
    try:
        # miio 插座开关命令（siid=2, piid=1 是标准小米智能插座3的属性）
        value = "true" if on else "false"
        result = subprocess.run(
            ["miiocli", "device", "--ip", PLUG_IP, "--token", PLUG_TOKEN,
             "raw_command", "set_properties",
             f'[{{"did":"","siid":2,"piid":1,"value":{value}}}]'],
            capture_output=True, text=True, timeout=10
        )
        if result.returncode == 0:
            log.info(f"插座已{action}")
            current_plug_state = on
            return True
        else:
            log.error(f"插座{action}失败: {result.stderr.strip()}")
            return False
    except Exception as e:
        log.error(f"插座{action}异常: {e}")
        return False


def main():
    global fail_count
    log.info("=" * 50)
    log.info("iPad 自动充电监控启动")
    log.info(f"阈值: ≤{LOW_THRESHOLD}% 开充, ≥{HIGH_THRESHOLD}% 停充")
    log.info(f"轮询间隔: {CHECK_INTERVAL}s, 失败保护: {MAX_FAIL_COUNT}次")
    log.info("=" * 50)

    while True:
        battery, charging = get_ipad_battery()

        if battery is None:
            fail_count += 1
            log.warning(f"读取失败 ({fail_count}/{MAX_FAIL_COUNT})")
            if fail_count >= MAX_FAIL_COUNT:
                log.error("连续读取失败达上限，强制关闭插座！")
                set_plug(False)
                fail_count = 0  # 重置，下次循环继续尝试
        else:
            fail_count = 0
            charge_status = "充电中" if charging else "未充电"
            log.info(f"iPad 电量: {battery}% ({charge_status})")

            if battery <= LOW_THRESHOLD and current_plug_state is not True:
                log.info(f"电量 {battery}% ≤ {LOW_THRESHOLD}%，开始充电")
                set_plug(True)
            elif battery >= HIGH_THRESHOLD and current_plug_state is not False:
                log.info(f"电量 {battery}% ≥ {HIGH_THRESHOLD}%，停止充电")
                set_plug(False)

        time.sleep(CHECK_INTERVAL)


if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:
        log.info("收到中断信号，关闭插座后退出")
        set_plug(False)
        sys.exit(0)
第五步：sleepwatcher 配置（Mac 休眠保护）
sleepwatcher 负责在 Mac 休眠时强制关闭插座，唤醒时重启监控。
5.1 安装 sleepwatcher
bash
brew install sleepwatcher
brew services start sleepwatcher
5.2 休眠钩子脚本 ~/.sleep
bash
#!/bin/bash
# Mac 休眠时执行：关闭 iPad 充电插座
echo "$(date): Mac 休眠，关闭 iPad 充电插座" >> ~/ipad_autocharge/sleepwatcher.log
miiocli device --ip 192.168.x.x --token 你的token \
  raw_command set_properties '[{"did":"","siid":2,"piid":1,"value":false}]'
5.3 唤醒钩子脚本 ~/.wakeup
bash
#!/bin/bash
# Mac 唤醒时执行：等待网络恢复，然后重启监控
echo "$(date): Mac 唤醒，等待网络恢复..." >> ~/ipad_autocharge/sleepwatcher.log
sleep 5
# 确保 tunneld 在运行
if ! pgrep -f "pymobiledevice3 remote tunneld" > /dev/null; then
    echo "$(date): 重启 tunneld" >> ~/ipad_autocharge/sleepwatcher.log
    sudo pymobiledevice3 remote tunneld &
fi
# 监控脚本由 launchd 管理，会自动恢复
bash
chmod +x ~/.sleep ~/.wakeup

第七步：已知缺陷与应对策略
表格
问题	原因	应对
iPad 重启后无线配对丢失	Apple 安全机制，重启后无线调试断开	脚本检测到连续失败 → 关插座；你需要偶尔拿 USB 线重新配对（lockdown wifi-connections --state on）
iPad 深度休眠，Bonjour 发现延迟	iPadOS 省电机制	脚本有 15s 超时 + 3 次重试，充电中的 iPad 不会深度休眠
Mac 换 Wi-Fi / 路由器重启	网段变化	插座和 iPad 都设静态 IP 或 DHCP 保留，避免 IP 漂移
tunneld 崩溃	偶发	launchd KeepAlive 自动重启；唤醒钩子也会检测重启
iPadOS 大版本升级	协议可能变化	升级后 pip3 install -U pymobiledevice3 更新到最新版
pymobiledevice3 大版本升级（CLI 命令改名）	例如 v9→v10 把 list-devices 改成 usbmux list、diagnostics battery 变 battery single	代码内已做候选命令自动兼容；文档以 v10+ 为准

方案总结
优点：
iPad USB-C 口完全自由，只插充电器，桌面零连线
电量读取走原生协议，比快捷指令上报稳定得多
多层安全保护：读取失败关插座 + Mac 休眠关插座 + 脚本退出关插座
